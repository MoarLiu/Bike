# Bike 1.6.1 运行时验证清单

日期：2026-11-09（Asia/Shanghai）。这是候选开发验证清单；结果另记，不借用 1.6.0 的通过记录。

| 范围 / 可见行为 | 操作与回退 | 功能证据 | 视觉状态 |
| --- | --- | --- | --- |
| 聚焦拖拽保留完整文档 | 多根文档进入聚焦；同级、子级拖拽；撤销、重做；保存后重开 | 实际鼠标拖拽、读取主存储核对全树 id 与关系 | 聚焦提示、拖拽落点、重开后完整大纲 |
| 导航不破坏撤销 | 编辑后搜索、反向链接定位折叠下的主题；撤销/重做；重复定位 | 键盘输入与快捷键、主存储 revision | 展开祖先、命中定位、撤销后文本 |
| 同步不循环或抢焦点 | 配置自动同步；编辑一次；等待编辑防抖与独立轮询；切换文档/主题 | 真实 React 调度与 HTTP 次数、DOM 焦点 | 同步状态、当前选择、草稿 |
| 同步失败收敛 | checkpoint 配额失败；下载保存失败；服务器切换；远端再次编辑 | 模块+内存 SQLite 与实际应用回归 | 可诊断错误、保留的本机内容 |
| 身份与格式 | JSON/带元数据 MD 往返；脑图改名后回 MD；空表格、代码、备注、Emoji/BOM/转义竖线 | 实际导出文件及导入；预览按钮的 UTF-16 范围与目标 id | Markdown 双栏、表格、代码、链接与损失提示 |
| 恢复与备份 | 读取失败列出并下载备用文件；导入前刷新最后草稿；拒绝伪造基线与旧窗口 | IndexedDB 故障、凭据与窗口生命周期回归 | 恢复入口、备份状态与错误提示 |
| 大库与资源 | 100 文档/20,000 主题搜索 20 次；单文档 20,000 主题/200 次独立编辑；深宽异常输入 | 固定 Node 测量与 Electron 输入、绘制、heap/RSS；预算与缓存计数 | 密集列表、脑图平移/缩放、受控错误 |
| AI 任务可结束 | 头后挂起 body；超量响应；取消后迟到结果；配置保存失败 | 真实 HTTP、实际取消按钮、保留编辑 | busy→取消→可继续编辑 |
| 桌面边界 | 生产单实例、关窗重开/退出、非主 frame IPC、正式包 CSP、自定义服务地址、更新页 | Electron 主进程/正常窗口输入、生产制品检查 | 初始原生窗口、菜单与弹窗 |
| 服务与 MCP | 413、双 SQLite 连接 CAS/锁等待、operations 分页、私有权限、符号链接、输出/嵌套预算 | 真实 HTTP/SQLite/文件系统与 MCP smoke | CLI/协议错误可读；路径默认脱敏 |
| 四视图与布局 | 浅/暗 × 1366×960/较大窗口；底部/右侧菜单；52%/250% 缩放 | 真实模式与主题切换，数值边界检查 | 每个模式、主题、窗口的截图检查 |

探索路径至少包括：聚焦根边界拖拽、同步期间切换选择并继续编辑、异常深层 Markdown 预览、底部菜单及重复链接候选选择。功能操作和截图检查分开记录。

原生中文输入法需要实际系统输入源取证；直接写入汉字不算输入法验收。真实跨设备 iCloud 传输需要第二台设备，只有本机目录证据时保持未验证。Linux/macOS 远端 CI、正式 DMG 与部署包安装/升级均须对同一候选单独取证。
