# Bike 1.7.0

发布日期 2026-11-09。本版交付桌面附件、完整归档、携图导出与应用内更新流程，macOS 分发按确认的范围继续采用 ad-hoc 签名。

## 新增与改进

- 桌面版支持选择、粘贴及拖入图片或文件，按 SHA-256 去重保存。大纲、脑图、Markdown 和演示共享附件引用，支持预览、另存、系统打开及撤销重做。
- 首次引入附件时升级到工作区 version 2，并保留升级前副本。纯文本工作区继续使用 version 1。
- 完整工作区 ZIP 携带正文、回收站及引用附件，支持校验、空白环境恢复和附件补齐。损坏对象可通过已校验 ZIP 修复，修复前保留损坏副本。
- Markdown/HTML 以携图 ZIP 导出，PDF 内嵌图片，脑图可导出 SVG、PNG 和透明 PNG。修复 PDF 中文字体子集化导致的缺字。
- 附件清理扫描正常文档、回收站、历史、撤销/重做、剪贴板及备用副本。候选进入隔离区保留 30 天，恢复引用时可取回。
- Sync 增加附件能力协商和旧客户端覆盖保护。MCP 读取返回附件身份，文本写入保留附件引用。iCloud 备份先写齐附件再提交工作区 JSON。
- 修复转义附件名、首次 Markdown 编辑身份，以及纯文本拉取后本机回收站附件的格式版本保留。
- 检查更新接入应用内下载、进度、稍后安装及保存工作区后重启安装流程，失败可重试。发布资产增加 ZIP 和对应更新清单，原生自动替换的签名条件见下文。

## 升级与使用边界

- 升级前保留工作区备份。完整附件迁移使用工作区 ZIP，单独 JSON 携带结构与引用。
- 先升级 Sync Server，再同步附件文档。本版同步附件元数据，其他设备通过 ZIP 补齐原文件。
- macOS 版本面向 Apple Silicon，原生组件和实际运行均为 arm64。Intel 与 Universal 仍处于评估阶段。
- Web 维护文本能力与附件元数据，附件文件导入、预览和完整归档通过桌面版使用。
- 本版应用采用 ad-hoc 签名，首次安装可能触发 Gatekeeper 安全提示。Developer ID 签名、公证和 stapling 留在后续分发工作中。
- 应用内检查与下载流程已接入，macOS 原生自动替换需要兼容签名。本版 ad-hoc 制品通过 DMG 手动升级，真实自动替换与重启验证需对应签名制品。

## 验收范围

三个 Node 版本各 362 项模块测试、23 项共享返回字段契约、TypeScript、生产构建、MCP smoke 及浏览器回归通过。DMG 只读挂载后的 13 项附件流程、7 项基础流程和 7 项受控更新流程通过，安装包文件匹配当前代码。

Web/Sync/MCP 归档经过干净依赖安装、登录、HTTP 426 旧客户端覆盖保护和覆盖升级验收。生产依赖审计为 0 项漏洞，开发工具链有 6 项既有 moderate 告警。

更新测试使用真实 `electron-updater` 实例并控制检查、下载与退出方法，覆盖保存保护和签名失败反馈。真实 Finder 拖入、系统剪贴板、中文输入法、完整多图/窗口矩阵、双设备 iCloud 与原生自动升级仍保留实机验证边界。

四项审查修复见 [审查记录](review-1.7.0.md)，更新协议见 [应用内更新](updates.md)。同提交远端 CI、最终制品和下载校验结果记录于 [发布验证](publish-verification-1.7.0.md)。
