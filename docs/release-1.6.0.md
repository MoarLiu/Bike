# Bike 1.6.0 更新说明

版本日期：2026-11-08

本版围绕个人知识连接与桌面自动备份，继续以 Electron macOS 桌面版为主，并提供 Web/Sync Server 部署包。

## 知识连接

- 在大纲、备注和 Markdown 中输入 `[[` 补全文档或主题，支持别名、特殊字符名称和“创建并链接”。
- 同名结果需要显式选择；已有绑定按目标 id 校验，不因旧目标删除后出现同名新对象而自动改连。
- 文档/主题改名时更新自动显示名，保留自定义别名；涉及多篇文档的同一次改名可以一起撤销。
- 可查看文档或主题的反向链接、来源路径、出链和失效状态；密集入链分批显示。
- Markdown 无法确定主题身份或引用来源时保留明确失效状态，供重新选择，不按相同路径猜测绑定。

## 检索与导航

- 搜索正文、标题和备注，支持多标签同时包含、文档范围、任务状态、仅收藏和代码/表格条件。
- 保存、恢复、改名和删除筛选；收藏、最近打开和筛选属于本机导航偏好。
- 从搜索、标签和连接打开具体主题时展开祖先并定位；脑图会缩放、居中到目标，再次打开同一主题也能重新定位。

## 主题关系

- 为同一文档内的主题建立独立有向关系，支持标签、来源/目标编辑、反转、删除及撤销。
- 脑图用虚线和标签显示关系，提供显示开关、选中主题筛选及总数/显示/隐藏数量提示。
- 关系不改变大纲树形父子结构；HTML 和 PDF 导出包含可读关系清单。

## 桌面自动备份

- 自动备份默认关闭，由用户在“桌面备份”中启用；不新增登录或服务器依赖。
- 只备份已确认保存到 IndexedDB 的版本。写入串行处理，较旧保存凭据和已淘汰任务不能覆盖较新内容。
- iCloud 文件被 MCP、其他进程或设备修改后暂停备份；用户可查看、载入外部版本或明确选择用本机内容替换。
- 载入外部版本先成功保存到本机，再确认文件基线和恢复自动备份。
- 关闭窗口或退出前刷新草稿并等待备份；修复 macOS 重开窗口跳过刷新、⌘Q 只关闭窗口而不结束进程的问题。
- 写入 iCloud 文件夹不等于跨设备传输已经完成，云端传输由系统处理。

## 格式、MCP 与界面

- JSON、同步和带 Bike 元数据的 Markdown 保留引用、关系及支持的扩展字段；导入副本统一重映射内部 id，保留外部目标。
- 普通 Markdown 为有损导出；代码、转义文本和多反引号示例不会生成伪链接或被目标改名改写。
- 前端与 MCP 共用 Markdown 和知识连接模块；部署包包含 `shared/`，MCP 精简读取保持有界。
- 节点详情继续默认收起，保留右上角手动展开入口。
- Electron 默认与最小窗口均为 **1366×960**，可以放大，不能缩到此尺寸以下。
- 新增筛选、关系、分页和备份控件沿用既有按钮、输入框、字体层级和浅色/暗色样式；长名称不会撑开详情栏。
- 更新 MCP SDK/Zod、Electron 42 和构建工具的兼容安全版本；生产依赖审计告警清零。

## 产物与升级

- `Bike-1.6.0-arm64.dmg`、对应 `.sha256`、`.dmg.blockmap` 和 `latest-mac.yml`。
- `Bike-Web-1.6.0-sync-server.tar.gz`：Web/Sync Server、MCP 和共享模块部署包。
- `SHA256SUMS-1.6.0.txt`：发布资产的 SHA-256 校验清单。

客户端为 macOS Apple Silicon，最低 macOS 12；沿用 ad-hoc 签名，未经过 Developer ID 签名和 Apple 公证。首次运行可能需要在系统设置中允许运行。

升级前建议导出工作区并保留同步数据库备份。Workspace 仍为 v1，版本历史和导航偏好仍只保存在本机。建议同时更新使用中的 Electron、Web 和 MCP；旧客户端虽能保留部分未知字段，但编辑 Markdown、复制或移动时不保证理解新知识连接语义。

## 验证与已知边界

- 本机 Node.js 22.13.0 全量测试、类型检查、生产构建及 MCP smoke 已通过，详细原生和布局证据见 [验收记录](acceptance-1.6.0.md)。
- 已验证当前系统拼音输入法、真实 Chromium 双窗口存储竞争、原生关闭/重开/退出，以及 iCloud 专用目录中的外部修改保护和恢复。
- 跨设备 iCloud、其他系统/输入法及真实 Linux/systemd 部署仍需对应环境验证；浏览器大库计时不作为 Electron 全链路计时。
- 原生验收曾观察到一次候选高亮与 Enter 结果不一致；同条件复测未能稳定重现，该观察尚未关闭。
- 构建依赖仍有来自 minimatch 的中危审计告警；相关打包模块不随应用运行时分发。未采用审计工具建议的跨主版本降级方案。
