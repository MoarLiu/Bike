### 四项实现缺口

1. **备注和 Markdown 源码补全**：共用 `LinkInput`，提供候选、上下键、Enter、Escape、显式重名选择及创建并链接；组合输入期间不处理 Enter。已用真实浏览器键盘验证备注和源码插入，系统原生中文输入法仍需后续验收。
2. **完整关系编辑与提示**：支持标签、来源、目标修改及重新连接；失效边显示缺失端点。脑图分别显示总数、绘制数、隐藏数及 200 条绘制预算，提供选中节点相关边筛选。
3. **高级筛选与管理**：接入多标签 AND、文档范围、任务、仅收藏、代码/表格开关；保存、恢复全部条件，并支持覆盖同名、重命名和删除。
4. **HTML/PDF 关系清单**：输出可读关系与缺失端点信息，HTML 转义内容。真实下载的 HTML 和 PDF 包含“主题关系”和修改后的标签；PDFKit 成功读取并渲染该 PDF。
