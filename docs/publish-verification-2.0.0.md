记录日期为 2026-11-10。正式封版为 `2.0.0`，开发分支为 `codex/development-2.0.0`，基线为 `187c452786e9f2633e70487bb80adf245f2c44b1`。用户已授权 review 通过后发布，真实 AI/MCP 接入和两台物理设备验证由用户后续补测。

## beta.2 开发候选检查

- Node 26.13.0 的 `npm run check` 通过，包含 437 项模块测试、30 个共享返回契约、TypeScript、生产构建、MCP smoke 和差异检查。Node 22.13.0 的同源 437 项测试通过。
- 最终 DMG 完整性通过。只读挂载后，严格 ad-hoc 签名、UI、2.0 双进程、Electron 基础、13 项附件、7 项受控更新、1.7.0 兼容及浏览器回归均通过，错误列表为空。
- 实际应用为 2.0.0-beta.2、Electron 42.11.18、内置 Node 24.19.0，运行架构为 arm64，Rosetta 为 false。15 个原生组件均为 arm64。
- DMG 中的 app.asar、ZIP 中的 app.asar 与本地打包目录一致。包内 38 个运行时文件与当前源码/前端 dist 逐项 SHA-256 一致，package.json 的运行时字段一致。更新清单版本、长度及 SHA-512 与最终 ZIP、DMG 一致。
- UI 通过浅色/暗色和两种窗口尺寸，包含 16 个弹窗实例、七项导出、键盘与外部关闭、字体与按钮、筛选收叠、右侧对齐及侧栏无外框操作。
- 实际 MCP SDK stdio 与 socket 完成四种未失焦草稿读取、组合输入拒读、双客户端竞争、相同身份竞争、拒绝后重试、批准回执、撤权和只读重连。读取或回执等待期间撤权的边界由六个实际应用回调用例验证。
- 实际 1.7.0 应用在新 profile 恢复候选导出的兼容 ZIP，再通过候选的完整备份/升级入口迁移回 v3。身份、Markdown、备注、任务、代码、表格、链接、关系、扩展字段、回收站及原附件保留，升级前 v2 正文与 ZIP 可读取。
- 真实 HTTP 附件回归在写出 512 KiB 后注入 ENOSPC，原件保留且没有安装损坏对象。服务重建后可续传并取得相同原始字节。
- Web/Sync/MCP 归档的 57 个文件与当前工作区逐项一致，包含共享契约、操作/附件服务及其文件锁和元数据依赖。Node 22.13.0 的 11 项干净安装/覆盖升级检查通过，包含协议升级、旧端 HTTP 426、checkpoint、原附件上传/安装/下载及私有文件 0600 权限。

旧 Electron 回归有一次在配置弹窗尚未关闭时点击后方 AI 按钮而超时。回归脚本增加表单作用域、校验及关闭等待后，同候选重跑通过。原始失败日志保留为 `verification/electron-runtime-before-form-wait.log`。

## 性能与时间样本

100 文档/20,000 主题和单文档 200 次编辑的打包 UI 样本保留 200 步历史。大文档的子主题折叠，通过 UI 编辑根主题。1.7.0 的编辑 p95 为 167.644ms。

| 最终候选样本 | 编辑 p95 | 相对基线 | GC 后 heap |
| --- | --- | --- | --- |
| 旧格式 | 184.278ms | +9.92% | 49.86MB |
| version 3 | 167.511ms | -0.08% | 34.09MB |

搜索 p95 的最大增长约 3.06%，未触发计划中的 20% 复核线。测量包含自动化输入、动画帧和搜索防抖。v3 夹具从预存基线开始，初始化不同，不能将 heap 差值描述为普遍内存优化。

最终包的小型本机夹具另测得，读取屏障往返约 10.11ms，确定性 provider 响应至提案显示约 43.80ms，点击批准至查询持久回执约 456.86ms，离线修改经三次手动同步收敛约 498.41ms。这些结果包含 UI 和协议开销，不包含真实模型等待，不构成物理网络 SLA。
