# Bike 1.6.1

发布日期：2026-11-09。稳定性维护版本，重点改善编辑安全、同步恢复、内容往返和大文档资源占用。

## 修复与改进

- 聚焦大纲中的拖拽针对完整文档执行，保留聚焦范围外主题；搜索和链接导航的自动展开不再破坏撤销。
- 同步成功后保留有效选择、聚焦与输入；无变化结果不触发新的编辑防抖。上传 checkpoint 保存失败时可继续处理其他文档，并按远端实际内容恢复共同基线，仍保留真实冲突。
- 服务地址分别保存同步状态；内容指纹排除易变时间戳，旧基线升级时保留对账保护。
- 修复部分来源组跨文档移动、回收站身份碰撞恢复及结构化改名后的 Markdown 内容维护，内部引用和关系端点按同一映射更新。
- 修复 Markdown 空表格单元格、单列表格及元数据正文区分；带元数据 Markdown 保留文档扩展与原始树。改善 XML 属性换行、非法字符处理、Unicode 文件名和 HTML 代码/表格输出，导出损失按格式说明。
- 工作区遇到坏文档或不支持的版本时停止部分迁移；读取失败仍可下载备用文件。备份校验当前窗口实际保存的来源凭据，并显示失败和关闭刷新超时。
- 撤销历史增加约 64 MiB 内存预算并复用树结构；内容摘要和搜索缓存复用不变数据。修复旧文档版本保留全量搜索索引导致的内存增长。异常深宽输入明确拒绝并保留原数据。
- AI 与同步请求的超时覆盖整个响应读取过程，并限制响应字节；支持取消 AI 请求和阻止迟到结果覆盖编辑。
- 桌面生产单实例、IPC 主窗口/主 frame 校验、已配置网络目的地址校验、CSP 与生产菜单保护；原子写保留私有权限、拒绝符号链接目标，活跃写者的锁不会仅因变旧被抢占。
- 同步服务对超限请求返回结构化 413；数据库争写有界等待并返回可重试错误；operations 支持分页与游标。安装/升级改善私有权限、systemd umask、危险卸载路径保护和密码输入说明。

## 验证与兼容性

- 本地 Node 22.13.0、22.22.2 各 326 项测试通过，类型/共享返回字段契约、生产构建、MCP smoke 与真实浏览器编辑/同步流程通过；同候选远端 CI 结果另记于发布验证。
- arm64 DMG 挂载后验证了启动、CSP、单实例、自定义 AI 地址、取消、原生撤销重做与保存关窗重开；包内模块导入和签名校验通过。
- Apple M4 的打包应用固定样本中，100 文档/20,000 主题搜索 p95：浅色约 278 ms、暗色约 244 ms，包含输入防抖与首批绘制。单篇 20,000 主题（子主题折叠）完成 200 次独立编辑后，GC 后 heap 约 47 MiB。数据不外推到所有主题展开或其他机器。
- 工作区格式继续为 version 1；升级前建议保留 JSON 工作区备份。元数据 Markdown 用于 Bike 间往返，普通 Markdown/OPML/FreeMind/HTML 的损失会提示。
- macOS arm64，沿用 ad-hoc 签名，未经过 Developer ID 签名与 Apple 公证。没有扩大 Intel/Universal 支持。
- 真实中文输入法组合输入、完整窗口/缩放/菜单矩阵、第二台设备 iCloud 传输、Linux systemd/真实代理部署仍保留验证边界。一次尚未稳定复现的链接候选选择观察继续跟踪，不宣称已修复。
