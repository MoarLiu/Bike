## 工程和运行时

- Node 26.13.0 的 `npm run check` 通过，包含 437 项模块测试、30 个共享返回契约、TypeScript、生产构建、MCP smoke 和差异检查。
- 目标 CI Node 22.13.0 的完整 437 项模块测试通过。
- 浏览器回归覆盖实际 React 编辑、拖拽、撤销/重做、IndexedDB、搜索和格式往返。
- 双隔离 Electron 进程与真实 HTTP Sync 完成离线并发、冲突比较和解决、原附件自动传输、保留远端编辑的撤销。
- 真实 MCP SDK 客户端启动 Electron `--mcp-live`，完成未失焦草稿读取、预览、应用批准、状态查询、UI 刷新和幂等重试。直接 socket 重用已提交身份并改变候选会拒绝。
- beta.2 的八个实际应用回调用例覆盖五类 AI 和三种模板的成功预览、拒绝、过期、生成中取消、无效输出、目标变化及切换文档。任务候选可只接受其中一组，原子组不允许空选择提交。
- beta.2 的同步用例覆盖 checkpoint 累计响应/正文预算、重复 tombstone、保留名称身份，以及服务端压缩 5,001 条操作后带着离线待传修改重新追赶。
- 附件实际 HTTP 用例在服务器写出 512 KiB 后注入 ENOSPC，验证未安装损坏对象、本机原件仍完整，服务重建后从已有偏移续传并取得相同原始字节。
- `test:compatibility-runtime` 在打包候选导出 v3 的兼容 ZIP，由实际 1.7.0 应用在全新 profile 恢复，再通过候选的备份/升级入口回到 v3。正文身份、Markdown、备注、任务、表格、代码、链接、关系、扩展字段、回收站和原附件均保留，升级前 v2 副本及 ZIP 可读取。
- UI 检查覆盖浅色/暗色、1366×960 和 1728×1117，包含 16 个弹窗实例、菜单七项、键盘/外部关闭、按钮字体、筛选收叠、右侧对齐、侧栏入口无外框和实际导出。
- 全部临时 profile 与正常工作区隔离，确定性 provider 使用虚构凭据。最终候选的 DMG、签名和打包应用结果见 [候选制品验证](publish-verification-2.0.0.md)。

beta.1 阶段模块性能样本 p95 编辑增长约 1.7%，GC 后 heap 增长约 0.14%。beta.2 最终包的固定 UI 样本中，旧格式编辑 p95 增长 9.92%，version 3 为 −0.08%，搜索 p95 的最大增长约 3.06%，低于本计划 20% 复核线。原始数据、折叠根主题样本和初始化差异见实施记录。该数据不替代实际网络吞吐、真实 provider 和物理设备证据。
