## 固定样本与资源结果

样本生成器为 `scripts/measure-performance.mjs`；Apple M4、arm64、Node 22.13.0。100 文档合计 20,000 主题搜索 20 次；单篇 20,000 主题进行独立改名。GC 后记录 `process.memoryUsage()`，历史字节按唯一对象估计，**不是 V05/V06 所要求的 Electron renderer 测量**。

| 指标 | 原基线 | 当前实现 |
| --- | --- | --- |
| 独立改名次数 | 20 | 200 |
| GC 后 heap 起点/终点 | 46.1 / 158.8 MB | 58.8 / 134.9 MB |
| 最终历史估计 | 旧实现没有该指标 | 42,052,196 字节，约 40.1 MiB，200 条 |
| 改名中位数 / p95 / 最大值 | 175.1 / 193.5 / 208.0 ms | 159.3 / 240.7 / 1,163.9 ms |
| 搜索中位数 / p95 / 最大值 | 69.3 / 72.3 / 94.9 ms | 0.008 / 0.041 / 165.5 ms；后续相同查询命中缓存 |

当前测量期间同机还运行了常规检查，因此耗时不能作为受控性能改善结论；缓存命中耗时不能当成冷搜索延迟。内存结果支持结构共享和预算实现，但不足以关闭输入延迟与 GC 趋势门禁。原始数据：[baseline](evidence-1.6.1/node-baseline.json)、[current](evidence-1.6.1/node-current.json)。
