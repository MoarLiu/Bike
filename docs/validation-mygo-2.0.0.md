# Bike MyGO 2.0.0 验证摘要

记录日期为 2026-11-11。本摘要保留可公开的构建与验证结论，原始进程记录、截图、临时目录和诊断输出留存于开发环境。最终制品摘要与发布状态见发布验证和 GitHub Release。

## 发布范围

产品为 macOS arm64 的独立 Bike MyGO 2.0.0，采用 Go 1.26.10、MyGO v0.8.3、WKWebView 和共享 React 前端。正式身份为 `com.bike.mygo`，更新选择 `mygo-v` 发布链。安装方式持续采用 ad-hoc 签名与手动 DMG。

用户已在 2026-11-11 授权完成剩余修复后执行发布流程。macOS 12/13、第二台物理 Mac、真实中文输入法、Finder/剪贴板/拖放、iCloud、真实 AI provider、外部 MCP 客户端及 Gatekeeper 体验由用户亲自验收，作为非阻断待办记录。

## 已完成的自动化与代码验证

- 36 个桌面桥成员与 Electron/TypeScript 契约对齐。
- Go File MCP 的 14 个工具、Live 的 15 个工具、资源、模板、prompt、批准回执与重复请求通过既有协议互通。
- 固定 JS/Go 写入差分、原件摘要、ZIP 往返、完整副本 journal 与独立身份、正文及附件同步已有自动化结果。
- 既有本地候选完成生产 WKWebView、四视图、真实文件导出、完整副本与跨宿主固定场景。每项历史结果在验收记录保留构建归属。
- review 的五项问题已修复，定向回归覆盖备份外部基线、关闭最终备份、Unicode 身份、迁移偏好恢复及上传生命周期。MCP 身份问题另经修复后的 Go CLI 实际写入确认。
- 启动退出等待前端关闭订阅，并仅对明确的加载中回执重试。繁忙、组合输入、加载错误和保存失败保留原保护行为。

## 大纲性能处理

原正式 Electron 2.0.0 与早期 MyGO 的 20,000 行展开大纲都曾超过 150 秒挂载期限。块流布局修复后，MyGO 已完成 50 次持久化编辑，历史 p95 为 11,040 ms，存在长尾。同轮源码重建 Electron 的第 13 次回读不匹配，部分结果保留为失败。

本次进一步稳定附件 Context，并让普通输入复用同步完成的文本框高度测量。20,000 行全部保留在 DOM 中，外部文字修改、撤销、字体、宽度变化及首次挂载仍执行正常高度校正。

相同宿主的三次分段诊断中，保存耗时从 3,326 / 2,633 / 2,700 ms 降为 1,589 / 1,900 / 1,867 ms，文本框高度读取从每次 3–4 次降为 1 次。计时包含输入、自动保存、IndexedDB 修订与正文回读以及绘制。该诊断用于确认方向，最终候选继续执行受影响场景的 50 次对照。

## 制品与验收边界

最终发布候选须包含上述修复，并核对源码、前端、版本、build、架构、签名及包内容摘要。严格包检查包括 DMG 挂载、复制安装、tar 解压和无 Node PATH 的包内入口。远端 CI 与最终候选结果完成后回写发布验证。

携图 ZIP 已有历史原生保存面板成功记录，后一次面板交互在焦点竞争期间超时。保存面板及其他人工真机交互按用户指定由其亲自复验。库级归档、原件与路径校验继续由自动化覆盖。
