# Bike MyGO 2.0.0 验证摘要

发布于 2026-11-11。正式版本为 stable build 15，源码提交为 `8d7cc9b69d425a454b8a8c18f2aeb013a3b4961b`，公开 Release 为 [mygo-v2.0.0](https://github.com/MoarLiu/Bike/releases/tag/mygo-v2.0.0)。本摘要保留可公开的验证结论，原始日志、截图和诊断数据留存于开发环境。

## 发布范围

产品为 macOS arm64 的独立 Bike MyGO 2.0.0，采用 Go 1.26.10、MyGO v0.8.3、WKWebView 和共享 React 前端。正式身份为 `com.bike.mygo`，更新选择 `mygo-v` 发布链。安装方式持续采用 ad-hoc 签名与手动 DMG。

用户已在 2026-11-11 授权完成剩余修复后执行发布流程。macOS 12/13、第二台物理 Mac、真实中文输入法、Finder/剪贴板/拖放、iCloud、真实 AI provider、外部 MCP 客户端及 Gatekeeper 体验由用户亲自验收，作为非阻断待办记录。

## 已完成的自动化与代码验证

- 36 个桌面桥成员与 Electron/TypeScript 契约对齐。
- Go File MCP 的 14 个工具、Live 的 15 个工具、资源、模板、prompt、批准回执与重复请求通过既有协议互通。
- 固定 JS/Go 写入差分、原件摘要、ZIP 往返、完整副本 journal 与独立身份、正文及附件同步已有自动化结果。
- 既有本地候选完成生产 WKWebView、四视图、真实文件导出、完整副本与跨宿主固定场景。每项历史结果在验收记录保留构建归属。
- review 的五项问题已修复，定向回归覆盖备份外部基线、关闭最终备份、Unicode 身份、迁移偏好恢复及上传生命周期。MCP 身份问题另经修复后的 Go CLI 实际写入确认。
- 启动退出等待前端关闭订阅，并仅对明确的加载中回执重试。繁忙、组合输入、加载错误和保存失败保留原保护行为。

## 大纲性能处理

原正式 Electron 2.0.0 与早期 MyGO 的 20,000 行展开大纲都曾超过 150 秒挂载期限。块流布局修复后，MyGO 已完成 50 次持久化编辑，历史 p95 为 11,040 ms，存在长尾。同轮源码重建 Electron 的第 13 次回读不匹配，部分结果保留为失败。

本次进一步稳定附件 Context，并让普通输入复用同步完成的文本框高度测量。20,000 行全部保留在 DOM 中，外部文字修改、撤销、字体、宽度变化及首次挂载仍执行正常高度校正。

早期三次分段诊断确认输入高度读取从每次 3–4 次降为 1 次。build 14 的正式 50 次测量仍暴露长尾，MyGO p95 为 9,900 ms，同源 Electron 为 3,859.3 ms，因此继续修复。后续 15 次定向诊断捕捉长尾，系统采样显示 WebKit 的绘制与事件区域更新占用明显。最终修复让隐藏行工具保留占位并跳过子树绘制，悬浮、活动行、键盘焦点和打开的 AI 菜单恢复正常显示。实际 UI 检查确认文本框位置与尺寸稳定。

## 制品与验收边界

最终 stable build 15 的 app/probe 使用同一源码与前端，构建工作区为 clean。源码指纹为 `6796e5c22a6672b34bc0166af4cffd8453ef90ee158bfafc399d6153a0b9145c`，前端 SHA-256 为 `6090fc39aa57e8b27d897831488980ebeaaec99b1f2ed4f33070088bd3bb5af7`，与最终 50 次测量的嵌入前端完全匹配。严格包检查通过 DMG 挂载、复制安装、tar 解压、完整包指纹、arm64/minos、实际 ad-hoc 签名、许可和无 Node PATH 的包内入口。安装包的启动早退及常规退出自然结束，分别约 171 ms 与 173 ms。

携图 ZIP 已有历史原生保存面板成功记录，后一次面板交互在焦点竞争期间超时。保存面板及其他人工真机交互按用户指定由其亲自复验。库级归档、原件与路径校验继续由自动化覆盖。

## 最终受影响场景的 50 次测量

| 指标 | MyGO | 同源重建 Electron |
| --- | --- | --- |
| 已挂载大纲行 | 20,000 | 20,000 |
| 完成编辑与持久化回读 | 50 / 50 | 50 / 50 |
| 中位数 | 1,307 ms | 2,472 ms |
| p95 | 1,701 ms | 3,576 ms |
| 最大值 | 7,049 ms | 3,813.4 ms |
| 空闲后总进程 RSS | 604,930,048 B | 835,747,840 B |
| 连续活跃采样 RSS 中位数 | 3,000,123,392 B | 2,604,621,824 B |

两端修订严格递增至 151，每次正文与修订来自同一个完成的 IndexedDB 事务。源码与前端在测量期间保持一致，失败与不完整场景均为零。本轮仅复测展开大纲，六场景整体完成标记因此保持 false，其余场景沿用注明构建归属的既有结果。

编辑 p95 低 52.4%，活跃采样 RSS 中位数高约 15.2%，空闲 RSS 较低。末次瞬时 RSS 分别为 3,125,116,928 B 和 2,481,291,264 B，受压缩与采样时点影响，保留该差异。对应总物理占用分别约 4.97 GB 和 6.84 GB。RSS 为归属进程求和，可能重复计算共享页。MyGO 仍有两次约 6–7 秒的极值。

原正式 Electron 2.0.0 的历史挂载超时与本次源码重建对照分别记录。本次合成输入结果用于同源性能复核，真实 IME 由用户人工验收。
