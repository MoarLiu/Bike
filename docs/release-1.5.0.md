# Bike 1.5.0 更新说明

发布日期：2026-11-08

Bike 继续面向个人知识整理，以 Electron macOS 桌面版为主。本版重点是编辑回退、文档恢复和本地版本历史。

## 撤销与重做

- 大纲、脑图和 Markdown 结构修改支持撤销/重做，包括文本、标题、备注、层级、移动、拖拽、删除、格式和 AI 写入。
- 顶栏提供撤销/重做按钮；支持 `Cmd/Ctrl+Z`、`Shift+Cmd/Ctrl+Z`、`Ctrl+Y`。Electron 编辑菜单和原生键盘输入统一分发，避免重复执行。
- 同一主题的连续输入合并为一个步骤；标题、搜索、备注和 Markdown 源码输入框保留原生文本撤销。
- 外部修改导致内容不匹配时，拒绝用旧撤销记录覆盖新内容并提示用户。撤销栈最多保留 200 步，重启或重新载入后清空。
- 修复 AI 润色后焦点输入框写回旧文字的问题；AI 请求期间切换文档或修改内容时保留新编辑并提示重试。

## 文档回收站

- 删除文档改为移入本机回收站，至少保留一个正常文档。
- 支持按原位置恢复、单条彻底删除，以及下载工作区备份后清空回收站。
- 同 id 文档已重新出现时，恢复为独立副本，避免覆盖当前文档。
- 删除新文档或打开回收站时清理超过 30 天的条目，最多保留 100 条。
- JSON 工作区导出、iCloud 备份及 MCP 写入保留回收站内容；Sync Server 不上传回收站，从服务端拉取时保留本机回收站。

## 本地版本历史

- 顶栏“版本历史”可查看时间、来源、标题、主题数量和层级预览，并显示新增、删除、修改主题的统计。
- 每次启动后首次编辑某篇文档，以及此后间隔至少 10 分钟再次编辑时，自动保存修改前版本；也可手动保存当前版本。
- 同步替换或删除文档前保存旧版本；恢复历史版本前先保存当前内容，恢复后可立即撤销。
- 恢复快照或同步保存快照期间出现新编辑时，取消替换，保留当前内容。
- 快照独立保存在本机 IndexedDB，不参与同步，也不包含在工作区 JSON 或 iCloud 备份中。每篇文档最多 50 个版本；超过 60 天时保留最近 3 个，20 MB 容量上限优先，至少保留最新 1 个。
- 历史存储读取失败或损坏会显示错误，写入失败不会阻止继续编辑。

## 兼容性与界面

- 沿用 Workspace v1 和现有同步协议，正常文档数据兼容。
- Electron 和 MCP 迁移保留扩展字段、任务标记、回收站文档原始 id，避免导出或代理写入时丢失。
- 最小桌面窗口下编辑和版本历史按钮可达，暗色模式正文使用对应背景。
- 增加 Linux/macOS CI，使用 Node.js 22.13.0 运行测试、类型检查、构建和 MCP smoke。

## 发布产物

- `Bike-1.5.0-arm64.dmg`：Electron macOS Apple Silicon 客户端，macOS 12 或更新版本。
- `Bike-1.5.0-arm64.dmg.blockmap`、`latest-mac.yml`：Electron 更新元数据。
- `Bike-Web-1.5.0-sync-server.tar.gz`：Web/Sync Server 部署包。
- `SHA256SUMS-1.5.0.txt`：上述文件的 SHA-256 校验值。

macOS 客户端沿用 ad-hoc 签名，尚未经过 Apple 公证；首次打开可能需要在系统设置中允许运行。

## 升级与限制

- 升级前建议导出工作区并备份同步数据库。回收站与版本历史属于本机；浏览器和 Electron 使用各自的数据目录。
- 旧版 Electron/MCP 写入可能丢弃回收站字段，建议将使用中的客户端和 MCP 一并更新。
- 同一文档在两端均有修改时仍使用 1.4.x 的文档级冲突处理，不自动合并正文。
- AI 验收使用受控测试响应，没有调用用户真实付费接口；macOS 12 实机兼容性及真实 Linux/systemd 安装仍需对应设备验证。
