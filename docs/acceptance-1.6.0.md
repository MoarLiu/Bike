# Bike 1.6.0 本机补充验收

日期：2026-11-08（Asia/Shanghai）。本记录的原生与布局验收对象为本地候选 `1.6.0-test.3`，不表示已发布。当时源码元数据为 `1.5.0`，测试包版本由 electron-builder 单独指定；后续发布准备已将源码版本更新为 `1.6.0`，正式候选验证另行记录。

## 当前结论

- Node.js 22.13.0：**288/288 测试通过**，无失败、跳过或取消；TypeScript、Vite 生产构建、MCP smoke 和差异检查通过。
- 原生环境：macOS 27.0.1 / Apple Silicon，Electron 42.4.0 / Chromium 148.0.7778.254。
- 已补齐当前机器上的中文输入法、原生窗口生命周期、真实 Chromium 双窗口存储竞争、iCloud 专用目录外部写入保护、主要布局矩阵和本地 DMG 检查。
- 跨设备 iCloud 实际传输、其他输入法/系统版本、最终提交对应的远端 CI 尚未验收。本记录不把这些项算作通过。

## 本轮修复

### 退出应用在刷新完成后继续结束进程

原生操作确认：旧逻辑按 ⌘Q 时会先被窗口关闭处理阻止；备份完成后只关闭窗口，macOS 进程仍保留。现在记录 `before-quit`，最后一个窗口完成刷新并关闭后继续退出。普通关闭窗口仍保留进程，系统激活后可以重开。

`electron/window-lifecycle.test.mjs` 新增对应回归。实际原生进程与挂载 DMG 中的应用均验证：关闭/退出前的最终文本保留，退出后进程结束，再启动能读到退出前的编辑。

### 新增界面沿用既有设计样式

参照原工具栏、AI 配置和版本历史弹窗，复用既有按钮、配置输入框、字体栈、主题变量、边框和圆角：

- 搜索筛选、保存筛选管理、知识连接分页与关系操作使用共用按钮样式。
- 关系目标/标签和筛选范围复用配置输入框样式；长主题名称不再撑开详情栏的网格列。
- 候选、搜索、反向链接使用 13px 正文和 11px 辅助信息；紧凑操作使用 12px，匹配旧工具栏字号层级。
- 备份弹窗沿用现有弹窗页脚操作和 X 关闭图标，校正复选框尺寸。
- 仅调整新增界面及其必要的溢出约束，未替换全局字体或重做现有界面。

浏览器计算样式核对：旧工具栏与新增紧凑按钮的字体栈相同、字号均 12px、字重均 620、圆角均 6px、边框均 1px。暗色/浅色备份弹窗也在原生 DMG 应用中查看。

| 场景 | 结果与证据范围 |

## 尚未关闭的边界

1. 只有当前机器，无法验证第二台设备从 iCloud 收到同一版本及跨设备冲突。已上传状态由系统确认；尝试清除本地下载缓存后，系统仍返回 Current，未观测到实际驱逐，因此不把重新读取相同摘要当作云端下载往返通过。
2. 初次原生操作曾观察到一次“显示选中已有目标、Enter 后创建新文档”的不一致。加入候选状态记录后，同条件拼音提交与粘贴查询复测正常，文档数保持 3；尚无稳定复现条件。保留该观察，未据此做猜测性补全修改，也未宣称该现象已修复。
3. 最终源码尚未提交，远端候选 CI 未运行；其他 macOS/输入法环境和 Developer ID 公证不在本轮已通过范围。
