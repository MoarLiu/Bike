## 已发现的问题

- 原提交只为部分编辑入口设置撤销意图，缩进、拖拽、删除等操作未进入撤销栈。
- 恢复历史版本等待快照落盘期间，缺少本机内容变化检查。
- 回收站迁移把正常文档和已删除文档共用 id 集合，可能改写历史 id；Electron/MCP 迁移还会丢弃扩展字段。
- 快照读取失败被返回为空列表，写入回调异常可能没有明确反馈。
- 拉取服务端工作区会丢掉本机回收站；同步前快照没有等待落盘。

## 结果

- Node.js 22.13.0：197/197 测试通过，类型检查、生产构建和 MCP smoke 通过。新增编辑集成、并发恢复、快照限额/损坏数据、桌面快捷键、MCP 实际写入回归。
- 真实 Chrome：通过文字/缩进/删除/拖拽撤销重做、跨文档剪切粘贴原子回退、回收站恢复与下载清空、历史恢复后撤销、刷新保留、跨页更新后拒绝旧撤销。
- AI：受控响应验证生成、焦点主题润色和逐步撤销；请求期间切换文档会取消应用结果。未使用用户真实接口。
- 实际 DMG 中的 `Bike.app`：确认版本 `1.5.0`，加载打包文件；验证原生 Command-Z/Shift-Command-Z 各执行一次、编辑、回收站、手动快照和退出重启保留。
- 隔离 Electron home：实际点击 iCloud 备份，确认 JSON 保留回收站；用户原有 iCloud 文件不受验收影响。
- 浅色/暗色、默认窗口及最小 980×640 桌面窗口检查通过，修正暗色正文和新增按钮布局；未发现主要控件裁切、正文不可读或横向页面溢出。
- 部署包使用明确文件清单生成并在隔离目录解压；Node.js 22.13.0 生产依赖安装通过，验证登录、1.5.0 生产静态资源、同步鉴权、中文文档往返、revision 冲突及退出登录后重启仍失效。
- DMG 完整性、只读挂载、应用版本、macOS 12 最低版本元数据和深度签名检查通过，沿用 ad-hoc 签名。远端 Linux/macOS CI 必须在同一发布提交通过后才创建 tag 和 Release。
- 未覆盖 macOS 12 实机、真实 Linux/systemd 安装和真实 AI 上游；这些限制已写入发布说明。
