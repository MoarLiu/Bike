# Bike 1.4.4 更新说明

发布日期：2026-11-08

## 编辑与数据保护

- 节点详情栏默认收起，编辑区使用可用宽度；右上角按钮可以展开或收起，备注修改会保留。
- 多标签页和窗口保存时检查工作区 revision，旧页面不会静默覆盖其他页面的新内容。冲突时可选择载入最新内容或使用本页内容，操作前先下载备份。
- IndexedDB 保存失败或关页前有未保存编辑时，各页面独立保留备用副本。其他页面保存以及较早保存延迟完成，都不会删除内容不同的新副本。
- 连续排队保存都失败时，备用存储保留最新请求的编辑；备用副本记录创建时仍在等待的保存，避免旧副本自动覆盖后来发起的新保存。
- 关页重开后，可在侧栏“备用副本 · 查看与恢复”中下载、恢复或下载后删除副本。当前数据库读取失败时暂停自动保存，避免回退旧库后覆盖新内容。
- 载入 iCloud 备份需要确认，并先下载当前工作区备份。

## 同步与安全修复

- 请求体按原始字节收集后一次性解码，修复分块传输中文损坏，大小限制也按字节计算。
- 远端删除与本机修改、本机删除与远端修改的冲突均以修改为准；文档顺序通过 revision 检查和合并保护其他设备的调整。
- 登录限流按 IP 和用户名计数；更换用户名不能重置同一 IP 的限流。限流期间在检查密码之前返回 429，已登录过的受信设备使用独立限流表。
- 限流记录只在过期后清理，不能用大量新身份挤掉已有账号的限制。验证成功的设备密钥会缓存，失败尝试限制在 PBKDF2 之前检查。
- 退出登录记录写入持久文件。升级旧 systemd Web 服务时自动添加状态目录配置并保留原服务设置；旧文件中的吊销记录迁移至新目录。
- Markdown 链接按浏览器 URL 规则过滤；静态页面和同步 API 的非法 URL 编码返回 400。

## 安装与平台调整

- 部署包 SHA-256 校验失败后立即停止，不再继续解压。Node.js 下载也强制校验。
- 管理脚本从已验证的指定版本部署包中安装，`update-script` 会下载整个部署包。固定为不含管理脚本的旧版本时，文件安装保留现有管理脚本。
- Electron 未配置开发服务器地址时加载打包页面，修复 `electron:start`。
- 当前发布和维护 Electron macOS Apple Silicon 与 Web/Sync Server；源码移除 Android、iOS、Swift Native、Windows 构建目标及相应说明。
- 同步服务需要 Node.js 22.13.0 或更新版本，安装器同时验证 `node:sqlite` 可用性。缺少合适运行时会准备独立的 Node.js 22，不覆盖系统 Node。
- 新配置项包括 Web 的 `auth.trustedProxyCount`、`auth.sessionStatePath`，以及独立同步服务的 `trustProxyHeaders`、`trustedProxyCount`。示例和中文文档已更新。

## 发布产物

- `Bike-1.4.4-arm64.dmg`：Electron macOS Apple Silicon 客户端，macOS 12 或更新版本。
- `Bike-1.4.4-arm64.dmg.blockmap`、`latest-mac.yml`：Electron 更新元数据。
- `Bike-Web-1.4.4-sync-server.tar.gz`：Web/Sync Server 部署包。
- `SHA256SUMS-1.4.4.txt`：上述产物的 SHA-256 校验文件。

macOS 客户端使用本地 ad-hoc 签名，未经过 Apple 公证；首次打开可能需要在“系统设置 → 隐私与安全性”中允许运行。此次不提供 Intel、Windows、Swift Native 或移动端安装包。

## 升级说明与已知限制

- 沿用 Workspace v1 和现有 SQLite 同步协议。升级前建议导出工作区并备份同步数据库；之前丢失的内容仍需从已有备份找回。
- 同一文档在两端均有修改，或首次同步存在相同 id 的不同内容时，仍报告冲突，需要手动选择上传或拉取，不自动合并正文。
- localStorage 备用容量有限；写入失败会报告错误。多个不同备用副本通过恢复入口处理，不能替代独立的工作区导出备份。
- 显式配置 `auth.sessionStatePath` 的部署仍需保证该位置可写；升级不会改变管理员自定义的路径、服务用户或启动命令。

- 真实浏览器验证双标签页冲突、备用内容保留、刷新和关页后恢复、下载备份内容及节点详情栏展开/收起。
