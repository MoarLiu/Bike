# Bike 1.6.1 本地候选验收

日期：2026-11-09（Asia/Shanghai）。分支 `codex/development-1.6.1`，基线 `0c98884`。发布已经用户明确授权；正在提交同候选远端 CI。本文保留本地候选证据，最终发布状态见发布验证记录。

## 交付

O01–O10 的本地实现已经完成。关键编辑、同步、身份、内容往返、恢复、网络与资源边界均有回归；候选 CI 配置、19 个公开返回字段契约检查、全部共享模块的运行时/声明导出名检查已接入。

续做补齐：不可变节点内容摘要与 v3 指纹升级（兼容 v2 候选基线）、恢复副本按 key/raw 缓存及容量限制、源码行表缓存、脑图场景在 pan/zoom 时复用；旧 systemd 的私有 umask drop-in；MCP Unicode 文件名、符号链接启动与真实包内导入检查。

打包性能验收发现并修复了额外的保留问题：以不可变文档对象为 key 的 WeakMap 索引缓存，会因为历史保留旧文档而保留每次编辑的全量索引。现改为每个 live document id 仅缓存最新版本，并清理已离开工作区的项；定向回归验证历史保留时缓存不会随版本增加。

## 打包应用性能

Apple M4 / arm64，Electron 42.11.18、Node 24.19.0、Chromium 148.0.7778.280；独立临时 userData。100 文档合计 20,000 主题，浅/暗各 20 次搜索，包含实际输入、180 ms 防抖、首批 DOM 与两个绘制帧；两个查询交替，含冷/热状态。

| 指标 | 修复后的打包应用 |
| --- | --- |
| 浅色搜索中位数 / p95 | 233.6 / 278.4 ms |
| 暗色搜索中位数 / p95 | 232.2 / 244.3 ms |
| 单篇大文档 | 20,000 主题，根主题可编辑，其余子主题折叠；200 次实际输入后失焦提交，均独立历史项 |
| 编辑中位数 / p95 / 最大值 | 166.7 / 168.8 / 511.1 ms；包括自动化输入、提交与两帧绘制 |
| GC 后 renderer heap | 0 次 30.7 MiB；20 次 46.4 MiB；100 次 46.6 MiB；200 次 47.2 MiB |
| 历史估计 | 200 条，约 19.2 MiB，低于 64 MiB 预算 |

修复前同样的打包测量在 200 次后达到约 1,536 MiB heap；修复后 20–200 次期间稳定，未发现继续按编辑次数线性增长。详见 [原始 renderer 测量](evidence-1.6.1/renderer-performance.json)。20,000 个可见 DOM 主题全部展开的交互性能未在此样本中证明，不扩大为任意树形/可见密度的保证。

Node 模块层使用节点摘要后，200 次独立改名中位数约 34.7 ms、p95 39.1 ms；见 [模块测量](evidence-1.6.1/node-merkle.json)。它用于定位实现成本，不能替代 renderer 数据。
